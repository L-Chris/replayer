## Fixes and improvements

- Aligned comic library, search, updates, history and reader controls with the shared application design. Chapter navigation now uses the same previous/next icons as the music player.
- Unified search fields, settings inputs and buttons. Fixed hover layout shifts, cramped favorites and clipped control borders; compact buttons and dropdowns now size to their contents.
- Cards now use background-only hover feedback and a hand cursor, with padding around artwork and text. Long lists reserve scrollbar space to prevent layout jumps between pages.
- Simplified music source labels to 网易云, QQ音乐 and 酷狗, and renamed the comic settings category to 漫画相关.
- Fixed missing video card thumbnails caused by playback metadata suppressing background extraction or overwriting existing artwork. Thumbnail extraction now skips black leaders, handles short clips and preserves portrait aspect ratios; video cards use landscape previews.
