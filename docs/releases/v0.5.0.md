## Feature

- Generate timed lyrics from local songs or downloaded online tracks through the playback bar's Lyrics menu, preserving the original language and automatically saving the LRC file; successful regeneration replaces the saved lyrics.

## Improvement

- Use system media and image services on Windows and macOS, with format support determined by installed codecs; Vorbis playback is currently unavailable.
- Show the global search field only on Home and simplify the Chinese Music tabs to Favorites and Search.
- Place file-opening and magnet-link actions beside the window controls.
- Let Home resume artwork fill its card without an outer inset.

## Fix

- Improve FLAC seeking, including backward jumps and jumps near the end of long files.
- Remove retired media components when upgrading the Windows application.
