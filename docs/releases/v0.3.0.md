## Feature

- Redesigned the application with a unified graphite and mint interface, custom Windows title bar, media library, favorites, recent history and distinct music, video and comic experiences.
- Added MangaYun comic search, chapter details, favorites, reading history, resume positions and update indicators. Read vertically or page by page, with a collapsible chapter sidebar.
- Added comic image translation through an OpenAI-compatible image editing service, with original, translated and comparison views. Configure `IMAGE_MODEL` and optionally `IMAGE_BASE_URL` / `IMAGE_API_KEY`; translations are generated only on request and cached separately from originals.
- Added synchronized lyrics, click-to-seek lyric navigation, and local LRC support. Improved music artwork and metadata display, downloads and the collapsible playback queue.

## Fix

- Restored smooth playback for high-bit-depth video by handling P010 and 10/12/16-bit YUV420 on the GPU.
- Improved comic loading with direct CDN access where supported, relay fallback, reusable connections, four concurrent page loads, read-ahead and cancellation of obsolete requests after navigation.
- Optimized image codecs in development builds. The same cached 850×1241 comic page took approximately 39 ms to read and decode, compared with 486 ms before the change; this is a local debug-build measurement, not a network download benchmark.
- Queue reordering now requires a 450 ms hold on the title area, preventing accidental dragging during normal clicks. Play and remove controls retain their click behavior.
- Fixed clipped button borders, slider handles and scrollbar overlap, and aligned comic reader controls with the shared application design.

## 新功能

- 重构整体界面，统一石墨黑与薄荷绿设计，加入自定义 Windows 标题栏、媒体库、收藏与最近记录，并区分音乐、视频和漫画的交互布局。
- 新增 MangaYun 漫画搜索、详情目录、收藏、阅读历史、断点续读与更新红点，支持条漫滚动、左右分页和可收起的章节侧栏。
- 新增兼容 OpenAI 图像编辑接口的漫画图片翻译，支持原文、译文与对照显示。配置 `IMAGE_MODEL`，必要时配置 `IMAGE_BASE_URL` / `IMAGE_API_KEY`；仅主动翻译时调用模型，原图与译图分别缓存。
- 新增同步歌词、点击歌词跳转及本地 LRC 支持，完善音乐封面、元数据、下载和可收起的播放队列。

## 修复与优化

- 为 P010 及 10/12/16 位 YUV420 视频加入 GPU 转色，修复高位深视频播放帧率低的问题。
- 漫画图片按来源选择 CDN 直连或转发，支持直连失败回退、连接复用、4 张并发、向后预加载，以及跳页取消过时请求。
- 单独优化调试构建的图片编解码依赖。同一张 850×1241 缓存漫画图读取与解码由约 486 ms 降至 39 ms；该数据为本地调试构建实测，不代表网络下载速度。
- 队列标题区域长按 450 ms 后才能拖动排序，减少普通点击误触；播放和移除按钮维持点击操作。
- 修复按钮边框、滑块手柄裁切与滚动条遮挡内容的问题，统一漫画阅读栏和其他页面的控件样式。
