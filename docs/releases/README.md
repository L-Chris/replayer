# Release notes

Before creating a release tag, add its notes as `docs/releases/vX.Y.Z.md`.
The desktop publishing workflow validates the file and uses it for the release
body. Rebuilding an existing release preserves its body. See [AGENTS.md](../../AGENTS.md) for
classification, translation, attribution and UTF-8 verification requirements.

```markdown
## Feature

- A short description of a new capability.

## Improvement

- A short description of an enhancement.

## Fix

- A short description of a corrected problem.

<details>
<summary>中文更新说明</summary>

## Feature

- 新功能的简短说明。

## Improvement

- 现有功能改进的简短说明。

## Fix

- 问题修复的简短说明。

</details>
```

Omit categories that have no entries. Do not publish this example as real notes.
