## Features and improvements

- Added Komiic as a comic source with guest search, chapter and volume directories, reading, favorites, history and update checks. Search sources return results independently; image tickets are requested only after a cache miss, refreshed once on expiry, and paused when the source reports exhausted quota.
- Improved comic scrolling and image loading with short request retention, shared in-flight loads, bounded caches of prepared pixels, and background decoding and pixel conversion. SIMD resizing speeds up large previews while preserving original files for translation.
- Unified comic covers to a cropped 3:4 aspect ratio across library, search, updates, history, home previews, detail pages and the reader's chapter list.
- Consolidated reader controls into the bottom toolbar, with compact display selectors, borderless chapter and zoom controls, a shorter page slider and a translation status icon with hover details. F11 toggles fullscreen; chapter lists start collapsed, and image panels no longer show a border or original/translated header labels.
- Centered reading images and comparison pairs, enabled wheel scrolling over images and margins, and kept chapter-list scrolling independent of the page.
- Embedded the comic source selector inside the search field, placed Komiic directly below All sources, and restored the brand area wherever the main sidebar is visible, including comic details.
