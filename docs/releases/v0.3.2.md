## Fixes and improvements

- Fixed DM5 comic chapters failing with an empty page list from MangaYun. The reader now falls back to the public chapter reader, resolves image URLs on demand and refreshes expired signatures while preserving the requested page. Cached pages remain available without resolving their URLs again.
- Unified back navigation as icon-only buttons with tooltips, and simplified the music search toolbar: quality selection now sits beside the source selector, with source configuration available in Settings.
- Removed the mini-player's lyrics caption, the comic detail refresh button and the bulk mark-all-read action. Individual chapter read actions remain available.
- Unified video and music grid card heights using square artwork areas while preserving artwork proportions.
- Reduced the bundled FFmpeg runtime from seven DLLs to five, saving **33.2 MiB after extraction**. Packaging verifies direct and indirect FFmpeg imports; upgrades remove the two obsolete DLLs. Installed playback checks run without FFmpeg from the build environment on PATH.

## 修复与优化

- 修复部分动漫屋漫画章节因 MangaYun 返回空图片列表而无法阅读的问题。自动回退到公开阅读页，按需解析图片地址；签名过期时刷新并保持原页码，已有图片缓存无需再次解析地址。
- 返回按钮统一为图标，保留悬停提示。音乐搜索的音质选择移到渠道右侧，音乐源配置统一从设置进入。
- 移除迷你播放栏的“歌词”文案、漫画详情页的“刷新目录”按钮和“全部标记已读”操作，保留单章标记已读。
- 视频和音乐网格卡片采用相同高度的正方形封面区域，封面保持比例裁切。
- FFmpeg 运行库由 7 个 DLL 精简为 5 个，解压后减少 **33.2 MiB**。打包时验证直接及间接依赖，升级时清理旧 DLL；安装后的播放检查不再依赖构建环境中的 FFmpeg。

Windows 提供安装版、便携版及 SHA-256 校验文件，可通过应用“设置 → 关于”检查更新。
