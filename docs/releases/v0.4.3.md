## Feature

- Add macOS application packages for Apple Silicon and Intel Macs.

## Improvement

- Reduce desktop runtime size while retaining playback and AI subtitle generation.
- Reduce image transfers for new comic translations while preserving existing cached translations.

## Fix

- Fix playback of videos with multichannel AAC, AC-3 or E-AC-3 audio when a compatible system decoder is available.
- Fix videos failing to open or seek when audio is buffered before the first video frame.
- Fix excessive waiting after backward seeks and playback errors caused by embedded subtitle tracks.
- Preserve seek positions and playback state when recovering from an audio device change.
